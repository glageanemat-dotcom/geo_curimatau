# geo_curimatau
GeoCurimataú é um jogo digital educacional de Geometria para estudantes do 6º ao 8º ano. Inspirado nas paisagens do Curimataú Paraibano e da Caatinga, propõe missões e desafios interativos envolvendo formas, polígonos, ângulos, perímetro e área, promovendo uma aprendizagem contextualizada, lúdica e significativa.
